# Engenharia de dados e automação com Python

Cinco projetos independentes em Python 3.11+, com documentação, exemplos e testes.

- [Warehouse ETL](warehouse-etl-python): pipeline CSV → SQLite.
- [Data Quality](data-quality-python): validação de contratos de dados.
- [Sales Insights](sales-insights-python): relatórios HTML de vendas.
- [DocSearch](docsearch-python): indexação e busca em documentos.
- [FileGuard](fileguard-python): integridade de arquivos com SHA-256.

Consulte o README de cada projeto para executar os exemplos e testes.
